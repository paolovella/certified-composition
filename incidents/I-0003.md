# The P1 compiler sketch existed only in a scratchpad, and it is gone

**What happened.** PLAN-2026-10 §4 says "the existing sketch is P1": a names-to-slots compiler
(`compiler-sketch/Compile.lean`), with a commuting-square theorem, written in an earlier
session's scratchpad. WI-001 (2026-10-23) split moving it onto branch `compiler/p1` out as
CMP-P1, and CMP-P1 was never started. On 2026-10-28, when Phase 1 needed it, no copy existed:
not in the repo, not in any scratchpad under `/tmp/claude-1000`, and not in `~/.claude/plans`.
What survives is the `compile` function and its target language, which S-KERNEL copied into
`bench/kernel/gen.py` to time it. The proofs (the square, and anything toward the frame
theorem) are lost.

**Why it mattered.** The plan names this sketch as Phase 1's first pass, and its square was
the evidence that P1 was cheap. That evidence is gone, and P1 is rebuilt from the plan's
description (PH1, step 5).

**What would have caught it.** The protocol rule already forbids leaving work only in the
scratchpad. WI-001 found the sketch there and filed an item instead of committing it. A
Stop-hook check that lists untracked `*.lean` files in the session scratchpad would catch
the next one. That needs a change to `.claude/` (Ring 0) and is proposed, not done.
