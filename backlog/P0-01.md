## Plan

1. `conf-typing/AxiomManifest.lean`: imports `ConfTyping` (which imports TransportCalculus); a
   `run_cmd` walks every *theorem* whose defining module is under `ConfTyping` or
   `TransportCalculus`, skips internal names, computes `Lean.collectAxioms`, and prints
   `name<TAB>axioms` sorted. transport-kernel (mathlib) is a follow-up item, not this one.
2. `tools/axioms.sh` regenerates `tools/axioms.expected`; CI diffs the committed file against a
   fresh run, so any footprint change is a visible diff.
3. `tools/axiom-claims.py` resolves doc claims mechanically:
   - table rows: a cell whose text is a footprint keyword binds every backticked name in the
     cell before it;
   - prose: a footprint keyword binds the nearest backticked name before it on the same line.
   Meanings: axiom-free = no axioms; propext-only = subset of {propext}; choice-free = no
   Classical.choice. A bound name that is a manifest theorem and violates its claim = DRIFT.
   Names that are not manifest theorems are counted as unresolved and reported, not failed;
   the resolved count is printed so it can be ratcheted.
4. check-claims calls 2+3; selftest cases: claim axiom-free for a theorem that uses choice;
   add a Classical.choice dependency to a claimed choice-free theorem (via manifest edit).
5. Every mismatch found on first run is recorded as a correction of record (CHANGELOG), and
   the doc is corrected, never silently.
