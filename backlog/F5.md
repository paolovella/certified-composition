## Plan

From [FOUNDATION-2026-10-29](../research/2026-10/FOUNDATION-2026-10-29.md), item F5. Ring 1, parallel across agents once F2 and F3 are stable; rows taken in order of severity.
On branch `f5/map` (from master, after the foundation merge #17).

**Every isolation row names its attacker** (the user's decision of 2026-11-02). `Cert.relView` stays
L's isolation claim, for an observer that can measure side channels: it refuses a program whose
timing, addresses, cost or path depend on the other tenant's data, so that tenant's code must be
constant-time in its data. A row may use `Cert.hyper` over the observer's events only if it states
that the observer cannot see side channels. Leakage partitioned by tenant was offered and not chosen.

**The map, row by row, against what is proved on an L language today** (2026-11-02). "On L"
means a `Cert` instance on `ucmdLangT` or `ucmdLangS` with an adequacy theorem; everything else
is proved, if at all, over a toy semantics that is not L.

**Kill rule check** (3 misfits of the same kind): the three misfits are of three different kinds
(quantitative, concurrency, assumption), so the rule does not fire. Rows 3 and 4 are the
evidence to watch: both want `rel` relative to a different equivalence, and if a third row wants
the same, `Lang`'s single `lowIn` is the thing to change before F6 locks more.

**Steps.**
1. **The map says what is on L.** `VULN-COVERAGE.md` gains an "on L" column with the theorem
   names above, and a correction of record for each row whose "IN" was a toy-language claim; a
   check-claims guard keeps every named L theorem in the axiom manifest.
2. **Rows 3 and 4 onto L**, the two that test `Lang`'s single `lowIn`: a taint-indexed and a
   release-indexed instance of `ucmdLangS`, and `pcheck`'s and `SecTyD`'s soundness as `rel`
   on them (or a recorded misfit).
3. Rows 6 (leaks), 7b, 9, 14 in order of severity; 12's component seams with the kernel.
4. Unused `Ev`/`Lk` constructors: `Ev.release` (row 4), `Ev.ext` is produced (faults),
   `Lk.vtime` and `Lk.ext` are produced by nothing: produced by a row's language or removed.

- 2026-11-02, **step 1 done: the map says what is on L.** `VULN-COVERAGE.md` §3.0: a
  correction of record (every verdict was proved over a toy model, and until F2 none was an L

  Check-claims guard (q): every L theorem the table names is in the axiom manifest; self-test 84.
- 2026-11-02, **the kill rule fires.** Rows 3 (injection), 4 (declassification) and 7b
  (isolation) misfit `rel` the same way: each is noninterference *for a particular observer
  under a particular input equivalence* (untrusted-agreeing inputs, one sink's queries;
  release-agreeing inputs; tenant-A-varying inputs, tenant B's outputs), while `rel` fixes
  both, to the language's `lowIn` and to equality of the whole observation. Three misfits of
  one kind: the shapes need another, before the kernel is locked further. Proposed (for the
  user's decision): `Cert.hyper R Θ`, a relational property of two runs' limits, which passes
  transfer through `Chain.Equiv` with one new input fact (coverage for `R`).
- 2026-11-02, **plan for row 3: injection is a `trace`, and L needs string inputs.** Two
  corrections to the plan above, from reading the checker.
  - Correction of record: the table and the kill-rule entry above say row 3 is relational
    (~~their integrity NI is a `rel` with a *different* Low-equivalence (taint)~~). `tcheck`
    proves no such thing: `TaintCert` says every emitted string's delimiter count is in `Ks`. That
    is a `Cert.trace`. Rows 4 and 7b are still relational, so the kill rule's "three" was two, and
    `hyper`/`relView` stay justified by those two and the user's decision on side channels.
  - **L has no entry point for untrusted strings.** `ucmdLangS.In` is `Store` and `initU` starts
    `sstore` empty, so on today's L the vulnerable query is safe because no attacker can reach it.
    Rows 3 and 7b both need this input.
  - **Build** (`ConfTyping/InjectionL.lean`, Ring 1, no kernel change): `ucmdLangI`, `ucmdLangS`
    with `In := Store × (String → UStr)`, lawful, and equal to `ucmdLangS` on empty strings.
    `injectionFree Ks`: every emitted payload's delimiter count is in `Ks`, prefix-closed.
    `tcheck_traceI`: `tcheck [] c = some (C', Ks)` gives `Cert.trace (ucmdLangI P π)
    (injectionFree Ks) c`.
  - **Attacker of this row:** controls every initial string variable. The observer is the sink.
    Side channels play no part: this is integrity of the query's shape, not secrecy.
  - **Witnesses:** accepted, `safeQuery` carries the certificate on every input; refused,
    `vulnQuery` fails it on the malicious input; and `vulnQuery` shows only two delimiters on
    empty strings, which is why the input is needed.
  - **Limits to state in the map:** "injection" here is the delimiter count over a two-symbol
    alphabet, `san` is quote-only (EXPR-04), and `tcheck` has no loop rule. `tcheckW`, which does,
    stays off L for now, since `TaintCert` says nothing about a run that never finishes.
  - **Done as planned.** `tcheck_traceI`, `ucmdLangI_lawful`, `ucmdLangI_empty`; witnesses
    `safeQuery_traceI`, `vulnQuery_traceI_fails`, `vulnQuery_empty_shows_two`. No kernel change.
