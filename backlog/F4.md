## Plan

From [FOUNDATION-2026-10-29](../research/2026-10/FOUNDATION-2026-10-29.md), item F4. On branch
`f4/lower` (from `f3/land`).

**The pass.** Three-address lowering of assignments on the lawful UCmd (`ucmdLangT` to
`ucmdLangT`): `assign x (add a b)` with compound operands becomes assignments to fresh
temporaries, then the final assignment. One source step becomes several target steps, the
cost of an assignment grows with its expression, and a partial target run can stop between
two of the temporaries. The compiler refuses a program that already uses a temporary's name.

**What the pass shows about the kernel, before code.** Today's `PassCert.sim` is one equation:
the target run at fuel `m` equals the source run at fuel `fuelT m` with leakage and cost
rewritten by maps of the program alone. This pass breaks it twice:
- the extra cost depends on *which* assignments ran, not on the source cost alone;
- a target run stopped between temporaries matches no source fuel exactly: its events equal
  the source's at the point before the assignment, but its cost does not.
So the equation becomes three obligations about the pass, which is still no certificate proof:
1. **events**: the target's events at fuel `m` are a prefix of the source's at `fuelT m`;
2. **cost**: the target's cost at `m` is at most `costB` of the source's at `fuelT m`, with
   `costB` monotone;
3. **determinacy**: two admissible inputs whose source observations agree at `fuelT m` give
   equal target observations at `m`;
plus **progress**, which no transfer uses but a compiler must meet: a source run that finishes
has a target run that finishes, with the same events and outcome. Without progress, a compiler
emitting a loop that does nothing would inherit every safety certificate.
`trace_transfer` then needs `Φ` closed under prefixes. On a lawful language that is already
what a `trace` certificate means: every fuel reports a prefix. `rel_transfer` follows from
determinacy, `bound_transfer` from the cost bound. Today's equation implies all four, so P1 and
the toy passes stay certified with one-line proofs.

**Steps.**
1. Kernel (Ring 0): the four obligations replace `sim`; `PrefixClosed`; the transfers and
   `seq` re-proved; witnesses: the existing passes rebuilt from their equations, and a refused
   pass that compiles everything to a loop doing nothing (it meets 1-3, fails progress).
2. The lowering (`conf-typing`, Ring 1): `lowerE`, `lower`, freshness check, and the
   simulation relation (target store = source store except the temporaries).
3. Its four obligations, then `bcheck`'s four certificates carried to the lowered program by
   the transfers alone (guard (m)'s rule extended to the new file), the budget transformed by
   the expression sizes.
4. **The kill rule's test**, stated now: if any obligation needs a fact about a particular
   certificate, PLAN-2026-10 section 6 fails, and this item stops and reports.

- 2026-10-30, **the user's decision: move UCmd to step fuel** (not a toy pair, not a replay
  proof on depth fuel). Plan, before code:
  - **Why.** `uexecT`'s fuel bounds nesting depth, so where a target run is at fuel `m`
    depends on program structure and path; `det` for any one-to-many pass then needs a replay
    proof per pass. With step fuel, and the step boundaries visible in the observation, every
    such pass's target observation is a function of the source's.
  - **`uexecS`** (new file `UStep.lean`): small-step UCmd on a frame stack, halting abort, the
    same events and leakage as `uexecT` in the same order, plus one marker per step
    (`Lk.ext "step" 0`). Unfolding a `seq` pushes its parts and costs no step; every step
    (atomic command, branch, loop test) costs 1. So a run out of fuel at `n` has cost `n`
    (the divergence law with `d = 0`), and more fuel only appends.
  - **Agreement** with `uexecT`: a finished small-step run has the same final state, events,
    branch bits, addresses, cost and outcome as `uexecT` at a large enough depth fuel (markers
    removed), and conversely.
  - **The four guarantees by reduction, not re-porting.** A `bcheck`-accepted program's
    `uexecT` run finishes (its budget and `bound_finishes`), so its small-step run finishes
    too, and every partial small-step run is a prefix of that finished run. Budget: partial
    cost <= final cost <= k. Mediation, memory safety: prefix-closed, so they hold of every
    prefix. Noninterference: two Low-equal runs finish with equal records, and the step
    markers align their prefixes; this needs one lemma about the language, not per pass: the
    marker-and-branch trace of a finished run is fixed by the program and its branch bits.
  - **Then the lowering** on `ucmdLangS`, with `det` as a function of the source observation.
  - `ucmdLangT` and its ports stay: they are what the reduction stands on.
