## Plan

The user's word of 2026-11-05: "work on the rules", after AI-01's proposal for a guard. `tools/` and `CLAUDE.md` are Ring 0.

1. **Rule (r) in `tools/check-claims.sh`.** It finds packages by searching, not from a list, so a new package cannot escape. Each lakefile must set the option at package level, on a line that is not a comment, and must never set it true anywhere, since a library's options override its package's. No Lean file outside `.lake` may `set_option autoImplicit true`.
2. **No exemptions.** `tools/gate/witness/lakefile.toml`, a sixth lakefile that AI-01's measurement did not cover, takes the option too. Its one Lean file is generated by `tools/gate/witness.sh`, and CI's witness step shows it still refuses.
3. **Witnesses in `tools/guard-selftest.sh`,** refused and accepted, for each way through. The count only rises.
4. **A house rule in `CLAUDE.md`,** so the next session knows why the error appears.
