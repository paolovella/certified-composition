# Plan: L — a self-evolving, AI-native secure language with a certificate-carrying compiler

*2026-10-23. Replaces the earlier draft. Evidence base: 10 research threads (§15) + an
independent architect pass, verified against the code where load-bearing.*

## Context

**Goal (user's words, consolidated):** a programming framework that is bulletproof — "it can't
break security"; a standalone language with its own compiler; **AI-native** ("safest and fastest
AI language", human-language output optional); scalable; and an **ecosystem that keeps evolving on
its own** — "a language that keeps evolving with countless agents using it and making it evolve,
starting from a really solid foundation that can't be exploited by any party", under **constant
challenge** because "there are no absolute truths".

**Decisions recorded:** standalone language + compiler · AI-native canonical form, human renderer
untrusted · full autonomy on green for everything **except** the trusted core and the gates, which
need the user's key · agents run in **both** cloud routines and on the local WSL box.

**What the repo is today (verified):** 95 Lean modules, ~1370 theorems, Lean v4.31.0, no `sorry`,
`native_decide` banned, 315 kernel-`decide` sites. Certificates live over **13 separate toy
languages**; the richest, `UCmd` (`Unified.lean`), carries budget, mediation, NI (`uOptLowEq`/
`uOptLowEqA`), memory safety, injection, path, leak — all predicates over `(UState, cost, trace)` of
`uexec`; speculative trace/cost over `uexecS`; races only counterexamples. **No code generator
exists.** Defects that shape the design:
- **Abort inside a loop diverges** (`uexec_dead_loop_diverges`, `a_dead_counted_loop_does_not_halt`
  — recorded as a language defect "of its own stage"): completed-run certificates are vacuous on
  such runs, and no compiler to real hardware (which traps and exits) can be exact against it.
- Pointers are `Int`s; integers unbounded — no machine meaning.
- ~235 doc claims "axiom-free/choice-free" never machine-checked; CI's Verus/Kani steps skip
  silently; `certcheck` not built in CI; **CI runs the PR's own `tools/ci.sh`, so a PR can rewrite
  its gate**; parser statement-layer round trip open; Lean 4.35 not installed (≤4.33).
- Mishap history: dozens of CORRECTION commits, doc drift, silent failed edits, abandoned
  uncommitted work, context loss, building before planning.

## 1. Organising principle: L is a process with a frozen core

| Ring | Contents | Changed by | Checked by |
|---|---|---|---|
| **0 Trusted core** (≤ ~2.5k LOC) | observation type, `Lang` interface, 3 certificate shapes + meaning, `PassCert` + composition, evolution meta-statements, control skeleton + `PrimSpec`, `W64`, wire format, RISC-V model + hardware contract, `Statements.lean` | **user's key** | read by a human; `lake comparator --paranoid`; `ring0.lock` hashes |
| **1 Proof-carrying extensions** | primitives, certificates, validators, passes, optimisations | agents, auto on green | must typecheck against Ring 0 meta-statements |
| **2 Proof-carrying programs** | corpus, libraries, apps (canonical AST + witnesses) | agents, auto | kernel-evaluated validator theorem per program |
| **3 Untrusted tooling** | witness inference, renderer, diagnostics text, optimiser search, schedulers, generators | anyone | believed only via a Ring 0/1 check |

If Ring 0 means what it says, an unsound Ring 1 change **cannot merge** — the kernels refuse it.
Residual risk is concentrated in: Ring 0 meaning, model gap (target model vs reality), toolchain,
and Goodhart on the evolution process. The challenge engine (§8) and threat model (§9) aim there.

## 2. Ring 0 artifacts (new package `l-core/`, mathlib-free, Lean 4.35, `LCore/Kernel/`)

- **`Word.lean`** — `W64 := {v : Nat // v < 2^64}`, ops via `Nat % 2^64` (kernel-fast, no
  `bv_decide`): wrapping `add sub mul and or xor shifts`, `ltu eq`, branch-free `select`; division
  only with public static-nonzero divisor. Unbounded `Int` only in specs/ghost (SPARK split).
- **`Obs.lean` — the ONE observation:**
  `Beh := {ev : List Ev, lk : List Lk, cost : Nat, out : Outcome, ret : List W64}`;
  `Outcome := done | abort code | fuel` (fuel = prefix only); `Ev` = check/read/emit/release/ext;
  `Lk` = branch/address/variable-time-operand/ext. Internal state (`hlab`, `freed`, `fresh`) is not
  observed — what certificates needed becomes leakage (addresses) or events (alloc/free).
- **`Lang.lean`** — `{Prog, In, lowIn, run : Nat → Prog → In → Beh, stable, prefix}`; `stable` +
  `prefix` let "∀ fuel" statements survive fuel-unit changes across IR levels.
- **`Cert.lean` — three shapes, meaning proved once:** `trace Φ` (prefix-closed; mediation, memory
  safety, taint/path, leak), `rel pub` (fuel-TSNI incl. leakage+cost; NI, cost-NI, lattice NI,
  integrity, bounded release), `bound k` (budget).
- **`Pass.lean` — `PassCert S T`:** `comp : S.Prog → Except Diag T.Prog`, input encoding `enc` with
  `encLow`, **leakage transformer `lkT` and cost transformer `costT` depending only on program +
  source leakage**, `fuelT`, `simDone` (target `Beh` = source `Beh` with transformed lk/cost),
  `simDiv` (divergence preserved, event prefixes), `costMono`, `erase` (residue-free).
  Proved once: `PassCert.comp` (transformers compose) and `trace_transfer`/`rel_transfer`/
  `bound_transfer`. **No certificate is ever proved per pass.**
- **`Core.lean`** — fixed control skeleton `skip|seq|ite|loop e bound body|call|abort|prim id args`;
  everything effectful is a row of a `PrimTable`. **Halting abort**, prefix-preserving `run`.
  `extend_conservative : q.id ∉ T.ids → ConservativeExt (Core T) (Core (q :: T))` — adding a
  primitive is conservative *by construction* (generalises the repo's `MemOp/SOp/HOp` bundling).
- **`Ext.lean`** — `CertDef` (shape, witness type, validator, per-primitive obligation `PrimObl`,
  `sound`), `PassDef`, `Package` (primitive + fresh id + every cert case + every pass case +
  accept/reject witness per cert), `EditionBreak` (migration + revoked certificates).
- **`Wire.lean`** — canonical prefix-tag/LEB128 AST encoding; `decode_encode` and `encode_decode`
  (canonical ⇒ hash identifies program). Replaces text grammar in the TCB; closes the parser gap.
- **`RV.lean` + `Contract.lean`** — RV64IM (~40 instructions) as a `Lang`, leakage = PC + address
  trace, cost = instructions retired; hardware contract as stated assumption (Zkt data-independent
  latency, no secret `div`, speculation window).
- **`Statements.lean`** — `binary_carries` (artifact accepted ⇒ every carried certificate holds on
  the RV `Lang` for the image bytes, under the computed ledger) + composition/transfer laws.

## 3. The language L

- **Proof-carrying programs: validate, never infer.** Artifact = Wire bytes + witness bundle: sorts
  (`w64|ptr|str`), lattice labels, capabilities, every loop's public bound + variant, tracked-pointer
  and auth sets at loop heads/joins, per-sink delimiter bounds, declassification sites, per-function
  contracts (labels, capabilities, cost, footprint, release), capacities (heap cells, string length).
  Validators: single-pass, linear, total, structural, kernel-evaluable, `Except Diag Unit`.
  b12's value-dependent bound becomes a witness check. Annotation burden is free for AI authors —
  this is what removes PLAN-2026-08 §4's Jif/FlowCaml objection.
- **`Diag`** — structured (AST path, rule id, expected/found witness, candidate repairs),
  deterministic; content untrusted, only `.ok ⇒ sound` is trusted.
- **Removed rather than proved** (Jasmin/FaCT/SPARK/HACL\* lessons): unbounded ints; secret-dependent
  traps; pointer arithmetic and ptr↔int casts (opaque `ptr`); address comparison; dynamic resource
  names (return as linear capabilities in edition 2); exceptions; recursion (call DAG, static stack
  bound); secret-dependent allocation size/count; secret `div`.
- **Memory:** v1 keeps the reuse allocator with secret-address retirement over `ptr` cells + stated
  capacity; arenas/static arrays with public indices are the first packages.
- **Mediation:** v1 static `check r`/`access r` primitives emitting events; policy π = monitor
  oracle (ledger entry). Edition 2: `Cap r` values only the monitor mints.
- **Sinks:** `emit k s`, `SinkKind ∈ {sql, shell, html, path, log, …}`, each with a delimiter
  classifier; the repo's 2-symbol `UCh` becomes the image of real bytes (`qcount (map cls s) = …`).
- **Consolidation of the 13 languages:** old modules move to `museum/` (built, frozen, not imported
  by L), each retired by a transfer theorem — `ucmd_to_core` (+ `uembed` for Cmd/WCmd); heap
  languages via UCmd; ACmd/ALCmd → `copy` primitive + may-alias witness; DCmd → `db.put/get`;
  QCmd → `sql` sink + escapers; SecTyD/TD → `declassify` emitting `release`; LatticeFlow → lattice
  labels; Integrity → dual-partition `rel` instance; Race/Interleave → concurrency edition; SCmd →
  superseded by Wire. Metric: `inductive .*Cmd` 13 → 1 (+ museum).
- **Human output:** one-way renderer/explainer of programs and certificates (Ring 3).

## 4. The compiler: canonical bytes → RISC-V bytes

**Target RV64IM**, not Clight/C (verified): C via gcc/clang provably breaks CT ("Breaking Bad");
CompCert-CT is an unmaintained 2019 Coq fork, adds a Lean↔Coq gap, no residue handling, NC
licence; RISC-V has fixed-length encoding, no flags, an official Sail model with a Lean backend, Zkt
as a written CT contract. Clight stays a later optional emitter for qualification, ledgered.

| # | Pass | lkT / costT | Residue obligation |
|---|---|---|---|
| V | validate (not a pass) | — | — |
| P1 | names → slots (the existing sketch) | id / id | frame: no write outside table |
| P2 | ANF / three-address | id / static per path | temporaries zeroed or label-typed (`temp_residue_leaks` = teeth) |
| P3 | structured → CFG, halting exit stub | `br b ↦` public label / per-block | — |
| P4 | cells/strings → linear memory, inline allocator | `addr a ↦ base+8a` / public fn of alloc history | freed cells zeroed, secret cells retired; premise `Fits cap` |
| P5 | slots → stack frame | id / static | zeroise caller-visible regs + frame at `ret`/`ecall` |
| P6 | instruction selection | → PC + address trace / instr counts | — (`select` → branch-free mask, never a branch) |
| P7 | layout | id / id | — |
| P8 | encode + static ELF, entry stub zeroes regs | — | — |
| P∗ | optimisations | via witness | via witness — translation validation: `if check p (opt p) w then opt p else p` is itself a `PassCert` |

Runtime is not trusted C: allocator emitted by P4 (proved), I/O shim is fixed asm per event kind
(proved in P6), OS/monitor behaviour is an FFI-oracle ledger entry.
**Compilability premises** proved at source: `MemSafe`, `Fits cap`, `NoSecretTrap`; else refuse
with `Diag`. **Residue:** `ResidueFree` = attacker-readable state (all regs, stack below sp, freed
cells) at every `ecall/ret/exit` is a function of public data (Besson et al. probing model;
zeroisation as in Jasmin TCHES 2024).

**Trust base, shrinking by stage**
- T1 — Wire + kernel-checked `validate p w = .ok ()` in generated `Artifact_<hash>.lean` (generator untrusted).
- T2 — **compile by kernel evaluation**: `pipeline R p = .ok img` by `decide`/`rfl`, `img` a literal;
  `lake exe` only generates files, never believed (running compiled Lean is unverified even in 4.35).
- T3 — RV model linked to Sail: per-instruction refinement proof, or co-simulation vs Sail emulator/Spike recorded as ledgered test evidence (spike S-SAIL decides).
- T4 — verified encoder (`decode ∘ encode = id`, injectivity, Nat div/mod lemmas).
- T5 — byte extraction: `img` read from the lean4export NDJSON the paranoid kernels checked, compared byte-for-byte with the file by an independent ~50-line script.
- T6 (always) — Linux loader/syscalls (or Spike/QEMU), hardware contract, kernels (5 under `--paranoid`). Every stage is a computed ledger entry in the attestation.

**Speculation:** `Lk` gains transient component, passes add public `specT`; P1/P2 easy, P3/P6
research-level (POPL 2025 did it in Coq). Fallback: SLH masking on every load under a branch;
until merged, certificate versioned "SCT: carried to Core only".
**Concurrency (edition):** `par` over ownership-disjoint threads, compiled to a deterministic
cooperative scheduler yielding at public points; real multicore out of scope, ledgered.
**Modular compilation:** callers validated against callee *contracts*; per-function objects with
`ObjCert`; `link_correct` (contracts match at call sites ⇒ composed certificate, **ledger = union**
via the repo's existing `Ledger`/`Bridge.comp`); foreign certificates (Jasmin SCT, CN,
mlkem-native) enter at link time as ledger entries — certified composition becomes the linker's
semantics. Robust safety vs arbitrary linked code ledgered until isolation (PMP/process).

**The existing sketch is P1**, adopted with fixes: commit to branch `compiler/p1`; `compile` returns
`Except Diag`, prove `covers (dedupVars c) c`; restate as `PassCert` once `Obs` exists; prove the
frame theorem; state NI for an observer of **Low slots + slots outside the table** (not "whole
memory" — High slots hold secrets until P5 zeroises); `colliding_slots_leak` = P1's reject witness.

## 5. One-time move from state to observation

Halting abort + `W64` + `ptr` change the semantics, so certificates are restated once on Core —
the last time. Transfer where possible: `ucmd_core_agree` (on `some`: equal events up to abort;
dead-divergence ↦ core abort); old witnesses become corollaries; `adeq_k` per certificate. Riskiest:
**JSecTy** (`uLowEqA` equates `freed`/`hlab`/`fresh`) — spike S-OBS; fallback: public-only allocator
(no reuse of cells allocated under secret control) as an edition-1 removal.

## 6. Scalability

**Proof cost = Σ_k Adeq_k(O(N)) + Σ_p Gen_p(O(N)) + S + 1 = O(N·(C+P))**, not O(N·C·P)
(N primitives, C certificates, P passes, S = 3 shapes).

| Change | Marginal cost |
|---|---|
| new primitive | C + P local lemmas; conservativity free |
| new certificate | N local lemmas + 1 shape instance; **0 per pass** |
| new pass | N local lemmas; **0 per certificate** |
| new program | 1 validator `decide` + 1 compile `decide`, linear |
| bigger program | per-function modules, incremental Lake rebuilds |

**Parallel cells:** (primitive × certificate) and (primitive × pass), one file each
(`LCore/Prims/Load/NI.lean`), registered by attribute `@[cell Load NI]`; registry computed by
metaprogram (`#registry_complete` fails elaboration on a missing cell) → no shared files, no
conflicts. Cell statements are **template instances** checked by `rfl` against frozen templates →
most new statements need no review tier.

## 7. Gates — the engine of fast, safe autonomy

- **Base-branch gating (non-negotiable first):** the gate runs from master's `tools/gate/` against the
  PR tree (`pull_request_target`-style split checkout); branch protection requires it. The WSL box
  becomes a self-hosted `heavy` runner (Verus, Kani, mathlib, paranoid comparator, RISC-V runs);
  offline ⇒ heavy-tier PRs wait (fail closed).
- **Tier classifier** (part of the gate) from diff paths + a **type manifest** (metaprogram hashing
  every declaration's elaborated type; "proof-only" = no existing type hash changed):

| Tier | Class | Gate (cumulative) | Merge |
|---|---|---|---|
| G-P | program/corpus | validator `decide`; `lake check`; banned tokens | auto |
| G-C | cell proof / template-instance statement | build; `lake check`; axiom-manifest additions only, allowed axioms; comparator vs frozen + generated challenges; `#registry_complete`; guards + selftest | auto |
| G-X | package (prim/cert/pass/opt/validator) | G-C + typechecks as `Package/CertDef/PassDef`; accept/reject pair per cert; mechanical rule mutants must all die; corpus impact (no accepted program newly rejected outside an edition break); budgeted adversary attack (agent + Kani/fuzz); heavy runner | auto on green |
| G-D | docs/claims | prose rendered from claim records; claim-free prose fails | auto |
| G-0 | Ring 0, gates, CI, CLAUDE.md/hooks, toolchain, ledger semantics, Statements | old gate passes + ratchets + two independent adversary reviews + `--paranoid` | **user's key** |

- **Ratchets** (never decrease without a G-0 retraction): selftest cases, mutants killed, witness
  pairs, frozen statements, paranoid kernel set, corpus-accepted set. Statement changes must come
  with `stmt_strengthens_<id>` (new ⇒ old).
- **Auto-revert:** a post-merge audit failure on a commit that passed opens a revert (auto-merged on
  green) + `incidents/I-####.md`, which must spawn a "guard that would have caught it" item.
- **Kill switch:** `AUTONOMY` = `full | cells-only | off`, read first by every agent and the merge
  bot; auto-downgrade on ≥2 reverts/7 days, any G-0 audit failure, a soundness entry, spend over
  budget, gate flake > 5%; each downgrade opens an issue for the user. Per-tier merge-rate caps.

## 8. The challenge engine — constant challenge, kept curious

Standing adversary roles (scheduled; every finding → `refutations/R-####.md` + Lean witness when
possible + backlog item):

| Role | Attacks | Method | Runs |
|---|---|---|---|
| Breaker-programs | accepted-but-unsafe programs | Kani on Rust port, Verus, witness fuzzing, **differential compiled-vs-interpreted** (QEMU/Spike binary vs `#eval Core.run`: events/ret/cost must match `PassCert` prediction) | local |
| Mutant hunter | unconstrained validator rules | mechanical mutants (never LLM-written) | both |
| Vacuity hunter | trivially-true statements | satisfiability witnesses, gutted-proof checks, uninhabited hypotheses | cloud |
| Model-gap hunter | Ring 0 vs reality | RV↔Sail↔Spike co-sim; cycle probes on hardware; new attack papers → Lean counterexamples | local |
| Assumption rotator | ledger/TCB entries | oldest unchallenged entry each cycle: discharge it or break it | both |
| Blind transcriber | expressiveness | external tasks (new CWEs, attack/compiler-bug papers, mlkem-native seams) written as L programs **without access to validator internals** | cloud |
| Reviewer-adversary | G-X/G-0 PRs | must produce a test/counterexample attempt log | cloud |

- **Budget per weekly cycle:** 50% build / 30% attack / 20% exploration; no refutations for 2 cycles
  ⇒ attack 50%, exploration 30%.
- **Stagnation alarms** (each triggers an attack cycle + digest): low refutation rate; slow corpus
  growth; oldest open cell > 21 days; no ledger entry challenged in 30 days; no new external task in
  14 days; mutant kill rate 100% for 4 cycles (mutants too weak → escalate operators); corpus
  acceptance 100% (tasks too easy — Goodhart).
- **External inflow:** monthly literature routine → `FIELD-YYYY-MM.md` diffed; papers → transcriber
  and model-gap tasks; tool bumps (Lean, Verus, Kani, Sail) re-run all receipts.
- **Use-driven evolution:** metric = **witness-expressiveness gap** on agent-written programs for
  external tasks, each failure classed (a) missing construct → Package item, (b) witness language
  can't express a true invariant → CertDef item, (c) agent failed in budget → tooling item; a task
  counts only if Breaker-programs can't refute it. **Kill:** >30% class (b) concentrated in
  unrelaxable rules for 2 cycles ⇒ stop adding surface, redesign the witness language. **Sealed
  holdout** task set scored monthly so evolving agents can't fit to it.
- **No absolute claims:** `claims/C-####.toml` (theorem, statement hash, edition, Ring 0 hash,
  validator/pass versions, model versions, ledger ids, accepting kernels, status live/revised/
  retracted, **flip counter**); all markdown rendered from records; > 2 flips ⇒ G-0 review + incident.
  Soundness tracker `soundness/S-####.md` (Ring 0 meaning, model gap, TCB only) + `revoked.tsv`
  honoured by the attestation verifier. Editions: conservative within, `EditionBreak` across.
